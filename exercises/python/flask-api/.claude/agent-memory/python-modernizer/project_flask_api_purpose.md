The flask-api project is an intentionally poorly-written Flask application used as a refactoring exercise in O'Reilly Claude Code training courses.

**Why:** Students practice modernization and security fixes on this codebase during hands-on labs (Lab 4-6 focus on refactoring). The "before" state needs to have clear, demonstrable anti-patterns.

**How to apply:** When modernizing, ensure changes are educational -- each fix should be clearly attributable to a specific anti-pattern. Preserve the overall application structure (users, notes, images) so the training narrative remains intact.
